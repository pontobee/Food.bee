# LancheSmart Product Context


## Produto

Nome:

LancheSmart


## Empresa

Produto desenvolvido pela .bee.


## Categoria

SaaS de gestão para negócios alimentícios.


## Público

- Lanchonetes
- Restaurantes pequenos
- Pizzarias
- Delivery
- Negócios alimentícios


## Problemas resolvidos

- Falta de organização nos pedidos
- Controle manual de estoque
- Dificuldade financeira
- Processos lentos


## Principais módulos

- Dashboard
- Pedidos
- Estoque
- Financeiro
- Clientes
- WhatsApp


## Objetivo

Ajudar pequenos negócios a terem mais controle e eficiência.


## Experiência do usuário

O sistema deve ser:

- Simples
- Rápido
- Fácil de aprender
- Profissional


## Não criar

Evitar:

- Sistemas complexos
- Interfaces poluídas
- Funcionalidades sem necessidade
