# .bee Brand Guidelines


## Marca

Nome:

.bee


## Posicionamento

A .bee é uma empresa de tecnologia que cria produtos SaaS para diferentes mercados.


## Personalidade da marca

A marca deve transmitir:

- Simplicidade
- Inteligência
- Confiança
- Organização
- Inovação


## Direção visual

Estilo:

- Clean
- Minimalista
- Premium
- Moderno


## Referências

Inspirado em:

- Linear
- Notion
- Stripe
- Vercel


## Identidade visual


### Cores principais

Amarelo .bee:

Uso:
- CTAs
- Destaques
- Elementos importantes


Preto:

Uso:
- Textos
- Contrastes


Branco:

Uso:
- Fundos
- Espaços limpos


## Interface

Sempre priorizar:

- Muito espaço em branco
- Hierarquia visual clara
- Componentes simples
- Design elegante


## Botões

Devem possuir:

- Bordas arredondadas
- Hover suave
- Transições rápidas


## Cards

Devem possuir:

- Fundo limpo
- Bordas leves
- Sombras discretas


## Evitar

- Excesso de cores
- Layout poluído
- Gradientes exagerados
- Visual genérico


## Sensação final

Toda experiência deve passar:

"Uma tecnologia simples que resolve problemas complexos."
